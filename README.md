# 📊 AI & BI Email Analytics Agent
## 🌐 مؤسسة ربا لتحليل البيانات وأتمتة التقارير الذكية

مرحباً بك في مستودع مشروع **الوكيل الذكي لتحليل المبيعات وإرسال تقارير البريد الإلكتروني تلقائياً**. تم بناء هذا النظام الاحترافي باستخدام لغة **Python** وباعتماد إطار عمل **FastAPI** لإدارة العمليات المستقلة في الخلفية دون التأثير على استقرار الويب.

### 🚀 مميزات النظام الأساسية:
* **ذكاء الأعمال (BI):** تحليل الصفقات والمبيعات تلقائياً واتخاذ قرارات وتوصيات استشارية ذكية بناءً على الأرقام.
* **أتمتة البريد الإلكتروني:** صياغة وهيكلة تقارير احترافية مخصصة لكل عميل بشكل فوري عبر خوادم الـ SMTP.
* **العمل غير المتزامن (Async/Background Tasks):** معالجة المهام الطويلة والضخمة في الخلفية بكفاءة عالية لخدمة آلاف العملاء متزامناً.
